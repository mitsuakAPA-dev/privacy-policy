# プライバシーポリシー — Scroll Reader
最終更新日: 2026-03-22
このプライバシーポリシーは、Chrome拡張機能「Scroll Master」（以下「本拡張」）が、どのような情
報を保存し、どのように利用するかを説明するものです。
## 1. 保存する情報
本拡張は、ユーザーが閲覧しているページに対するスクロール位置を復元するため、次の情報をユー
ザーの端末内に保存します。
- ページ識別子（`origin + pathname` を SHA-256 でハッシュ化した値）
- スクロール位置の進捗パーセンテージ
- 保存時刻
- 拡張の設定情報（オーバーレイ表示の有効 / 無効、保存の有効 / 無効）
本拡張は、これらの情報をそのままのURLとして保存しません。ページ識別子はハッシュ化されます。
## 2. 保存先
上記の情報は、Chrome のローカル保存領域である `chrome.storage.local` にのみ保存されます。
本拡張は、保存データを独自サーバー、第三者サーバー、解析サービス、広告ネットワーク、外部の
データベースへ送信しません。
## 3. 利用目的
保存された情報は、次の目的にのみ使用されます。
- 同じページに戻ったときに、前回のスクロール位置を復元するため
- ユーザーが選択したオーバーレイ表示設定を保持するため
- ユーザーが選択した保存機能の有効 / 無効を保持するため
## 4. 寄付リンクについて
本拡張には、開発者の任意の寄付ページへ移動するためのリンクが含まれる場合があります。
このリンクは、ユーザーがクリックしたときのみ外部サイトを開きます。本拡張がクリック前にユー
ザー情報を寄付先へ送信することはありません。
寄付先のウェブサイトにおける情報の取扱いは、当該サイトのプライバシーポリシーに従います。
## 5. 第三者提供
本拡張は、保存した情報を第三者へ販売、貸与、共有、提供しません。
## 6. ユーザーによる制御
ユーザーは、拡張のポップアップから次の操作を行えます。
- オーバーレイの表示 / 非表示の切り替え
- ページ進捗の保存の有効 / 無効の切り替え
保存済みデータを削除したい場合は、Chrome の拡張機能管理画面から本拡張のデータを消去するか、本
17
拡張を削除してください。
## 7. データ保持期間
保存された情報は、ユーザーが削除するまで端末内に保持されます。
## 8. 子どもの利用
本拡張は一般向けのツールであり、特定の年齢層を対象にしたデータ収集は行いません。
## 9. プライバシーポリシーの変更
本ポリシーを変更する場合は、本拡張の更新時または公開ページ上で新しい内容を案内します。

本拡張に関するお問い合わせ先: `apa.personaldevelopment@gmail.com`

# Privacy Policy

This extension stores the following data locally:

- Scroll position
- User settings

All data is stored using chrome.storage.local and is not transmitted to external servers.

This extension does not collect personal information.
